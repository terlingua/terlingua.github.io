## Learning objectives

- Choose between classes, structs and records
- Use primary constructors and `required` members
- Write expressive logic with pattern matching

## Records

```csharp
public sealed record Product(string Sku, string Name, decimal Price);

var a = new Product("B-1", "Book", 12m);
var b = a with { Price = 10m };   // non-destructive mutation
Console.WriteLine(a == b);        // False
Console.WriteLine(a);             // Product { Sku = B-1, Name = Book, Price = 12 }
```

Positional records generate `init`-only properties, a deconstructor, value equality and a readable
`ToString`. `record struct` gives the same features for value types.

## Primary constructors

```csharp
public sealed class OrderService(IOrderRepository orders, TimeProvider time, ILogger<OrderService> logger)
{
    public async Task<Order> PlaceAsync(Cart cart, CancellationToken ct)
    {
        var order = Order.From(cart, time.GetUtcNow());
        await orders.AddAsync(order, ct);
        logger.LogInformation("Placed order {OrderId}", order.Id);
        return order;
    }
}
```

The parameters are captured, not exposed. They are mutable, so if immutability matters, assign
them to `readonly` fields.

## Required members

```csharp
public sealed class SmtpOptions
{
    public required string Host { get; init; }
    public int Port { get; init; } = 587;
}
```

## Pattern matching

```csharp
static decimal ShippingCost(Order order) => order switch
{
    { Total: >= 100m } => 0m,
    { Destination.Country: "US", Weight: < 1.0 } => 4.99m,
    { Destination.Country: "US" } => 9.99m,
    { IsExpress: true } => 29.99m,
    _ => 19.99m
};

static string Describe(int[] values) => values switch
{
    [] => "empty",
    [var only] => $"one item: {only}",
    [var first, .., var last] => $"from {first} to {last}"
};
```

The compiler warns when a switch expression is not exhaustive, turning missing cases into build
feedback rather than runtime surprises.
