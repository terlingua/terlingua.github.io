## Learning objectives

- Structure prompts with roles, context, format and constraints
- Know what a system prompt is and is not
- Manage prompts as versioned, tested artefacts

## A well-structured prompt

```text
[system]
You extract fields from supplier invoices for the accounts-payable team.
Return JSON matching the schema. If a field is missing, use null — never guess.

[user]
<schema>{"invoice_number": "string", "total": "number", "currency": "ISO 4217"}</schema>
<invoice>
...invoice text...
</invoice>
```
